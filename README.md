# vk-group-market-scanner

vk-group-market-scanner - это инструмент для автоматического сканирования и сбора информации о товарах в группах ВКонтакте, на которые подписан пользователь.

## Описание

Проект предназначен для парсинга товаров из маркетов групп VK. Он использует Selenium для автоматизации браузера, собирает данные о товарах (название, цена, описание, изображения) и сохраняет их в локальную базу данных SQLite.

**Важно:** Инструмент работает только при условии, что профиль пользователя VK не скрыт от неавторизованных сессий. Убедитесь, что настройки приватности профиля позволяют просматривать подписки без авторизации.

## Особенности

- Автоматическое получение списка подписок пользователя
- Сбор информации о товарах из каждой группы
- Скачивание изображений товаров
- Сохранение данных в базу данных

## Установка

### Требования

- Python 3.8+
- Google Chrome или другой браузер с поддержкой WebDriver

### Шаги установки

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/vk-group-market-scanner.git
   cd vk-group-market-scanner
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Настройте конфигурацию:
   - Отредактируйте `src/config/user.py` и укажите URL профиля VK пользователя

4. Запустите приложение:
   ```bash
   python src/main.py
   ```

## Использование

После запуска программа автоматически:
1. Перейдет на профиль пользователя
2. Получит список подписок
3. Просканирует товары в каждой группе
4. Сохранит данные в базу данных

Результаты сохраняются в папке `src/data/database/`.
